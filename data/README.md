# Question bank — `items.json`

This directory holds the anchor item bank for the Irish maths diagnostic agent.

`items.json` is an array of `Item` objects (see `packages/core/src/types.ts`).
Each item is hand-calibrated with a Rasch difficulty `b ∈ {-2, -1, 0, 1, 2}` and tagged with:

- `stage`: `'primary' | 'junior_cycle' | 'leaving_cert'`
- `strand`: one of six Project Maths strands
- `learningOutcome`: NCCA outcome code (e.g. `JC.AL.U.4`)
- `correctIndex`: `0 | 1 | 2 | 3` into `choices`

Full schema and difficulty rubric: `docs/plans/2026-05-02-maths-diagnostic-agent-design.md`.

`items.json` itself is generated by a parallel agent — do not edit by hand mid-hackathon.
